# calculations
Wrote some simple python code to calculate big sums or integrals unfeasible to do by hand

Download both files. You only need to run pi_appr.py to obtain the approximation of pi using Viéte's formula. https://en.wikipedia.org/wiki/Vi%C3%A8te%27s_formula

At n=8 the precision becomes worse due to the approximative nature of the square root, so python doesn't calculate it precisely.
